# T-D-Python-Assignment-05-Titanic-Survival-Prediction-using-Naive-Bayes-Classification
Developed a classification model to predict passenger survival on the Titanic using the classic Titanic dataset.
The project covered data cleaning (handling missing Age and Cabin values), encoding categorical variables (Sex, Embarked), and implementing a Naive Bayes classifier to predict survival outcomes. 
Evaluated model performance through accuracy, confusion matrix, and classification report, and analyzed which passenger attributes (class, gender, age) most influenced survival likelihood.
